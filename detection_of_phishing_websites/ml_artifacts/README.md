# PhishGuard model artifact

Run `python train_models.py` from the repository root after installing the pinned
requirements. The command creates `phishguard_model.joblib` in this directory.

The `.joblib` file is intentionally not generated by the source ZIP. It must be
trained using the pinned scikit-learn version (`1.5.1`) and the included dataset,
then committed/deployed with the application. Do not load joblib files from
untrusted sources.
